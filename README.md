
# Автоматизация управления данными и резервного копирования
## **Automation of Data Management and Backup**

Этот проект выполняет несколько задач, связанных с управлением данными, их обработкой, сериализацией, созданием резервных копий и восстановлением данных. Скрипт автоматически создает структуру директорий, генерирует файлы с разным содержимым, обрабатывает их и сохраняет результаты в JSON-файле. Также реализована функциональность для создания резервных копий и восстановления данных.

## Описание

Проект включает в себя следующие этапы:

1. **Создание и управление директориями**:
   - Автоматическое создание структуры директорий для проекта.
   - Логирование выполнения всех действий в лог-файл.

2. **Создание и запись данных в файлы**:
   - Генерация примеров текстовых файлов с различными кодировками (UTF-8, ISO-8859-1, ASCII).
   - Заполнение логов с датой и временем создания файлов.

3. **Чтение и обработка данных**:
   - Автоматическое чтение всех файлов из директории `data/raw/`, определение их кодировки и обработка текста (замена заглавных и строчных букв).
   - Сохранение обработанных данных в директории `data/processed/`.

4. **Сериализация данных**:
   - Сериализация данных из обработанных файлов в один JSON-файл, содержащий информацию о каждом файле, включая имя, исходный и обработанный текст, размер и дату последнего изменения.

5. **Создание резервной копии**:
   - Архивирование всех файлов из директории `data/` в формат ZIP с именем `backup_<дата>.zip`.

6. **Восстановление данных**:
   - Восстановление данных из архива резервной копии, восстановление структуры директорий и данных.

## Как запустить

1. Установите все необходимые зависимости:
   ```bash
   pip install chardet jsonschema
   ```

2. Запустите скрипт:
   ```bash
   python main.py
   ```

3. Скрипт выполнит все шаги от создания структуры директорий до восстановления данных из резервной копии.

## Структура проекта

- **main.py**: Основной файл, содержащий логику выполнения всех задач.
- **project_root/data/raw/**: Директория для хранения исходных файлов.
- **project_root/data/processed/**: Директория для хранения обработанных файлов.
- **project_root/logs/**: Директория для хранения логов выполнения скрипта.
- **project_root/backups/**: Директория для хранения резервных копий.
- **project_root/output/**: Директория для хранения итоговых результатов в JSON и текстовых отчетах.

  ```
project_root/
     ├── data/
     │   ├── raw/
     │   ├── processed/
     ├── logs/
     ├── backups/
     └── output/
  ```

## Пример результатов

1. **Файлы в директории `data/raw/`**: Пример текстовых файлов с различным содержимым и кодировками.
2. **Файлы в директории `data/processed/`**: Файлы с преобразованным содержимым (сменой регистра).
3. **JSON файл в `output/`**: Итоговый файл `processed_data.json`, который содержит данные всех обработанных файлов.

Пример данных в файле `processed_data.json`:

```json
[
  {
    "file_name": "example1.txt",
    "text": "HELLO, WORLD!",
    "text_processed": "hello, world!",
    "file_size": 1024,
    "last_change_time": "2024-01-01 12:00:00"
  },
  {
    "file_name": "example2.txt",
    "text": "ПРИВЕТ, МИР!",
    "text_processed": "пригвет, мир!",
    "file_size": 2048,
    "last_change_time": "2024-01-01 12:00:00"
  }
]
```
